# 움직이는 지구과학 — 해수의 운동과 순환

고등학교 지구과학 「해수의 운동과 순환」 단원을 위한 **인터랙티브 과학 개념 팝업북**입니다.
교과서의 그림을 클릭하고 단계를 넘기면 그림이 움직이며 원리를 보여 주고, 마지막에 내신 수준 확인 문제로 이해를 점검합니다.

## 학습 콘텐츠 (10개)

| 번호 | 제목 | 핵심 조작 |
|---|---|---|
| 01 | 깊이 내려갈수록 수압은? | 잠수부 클릭(10 m씩 하강), 밀도가 다른 해수 선택 |
| 02 | 해수면이 기울어지면? | 왼쪽 해수면 높이기, 기울기 반대로 바꾸기 |
| 03 | 해류는 왜 옆으로 흐를까? | 재생(전향력이 운동 방향을 따라 회전), 북반구/남반구 |
| 04 | 바람이 불면 해수는 어디로? | 층별 해류 순차 등장(에크만 나선), 북반구/남반구 |
| 05 | 바닷물이 올라오고 내려가는 이유 | 용승/침강 선택, 번갈아 비교 |
| 06 | 파도는 물이 앞으로 가는 걸까? | 재생, 물 입자 클릭(궤적 강조), 마루·골·파고·파장 표시 |
| 07 | 파도는 왜 해안에서 부서질까? | 4단계 구간 강조, 파속·파장·파고 카드 |
| 08 | 지진해일은 왜 높아질까? | 해저 지진 발생, 지진해일/폭풍해일 비교 탭 |
| 09 | 달과 태양이 일렬로 서면? | 달 위치(삭·상현·망·하현) 선택, 조차 게이지 |
| 10 | 하루 동안 바닷물 높이는? | 시간 재생, 시간 슬라이더, 조류 화살표 |

각 페이지는 `단계별 설명 → 확인 문제` 순서이며, 문제를 맞히면 학습 완료로 저장됩니다(브라우저 localStorage, 로그인 없음).
키보드 ← / → 로도 단계를 넘길 수 있습니다.

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 터미널에 표시되는 주소(기본 `http://localhost:5173`)를 엽니다.

## 빌드와 배포

```bash
npm run build
```

`dist/` 폴더가 완성된 정적 웹사이트입니다. 빌드 결과를 로컬에서 확인하려면:

```bash
npm run preview
```

- `vite.config.ts`의 `base: './'`와 해시 라우팅(`#/lesson/3`)을 사용하므로, `dist/` 폴더를 **어떤 정적 호스팅의 어떤 하위 경로에 올려도** 그대로 동작합니다(GitHub Pages, Netlify, Vercel, 학교 웹 서버 등).
- **GitHub Pages**: `dist/` 내용을 `gh-pages` 브랜치에 올리거나, 저장소 Settings → Pages에서 GitHub Actions로 `npm ci && npm run build` 후 `dist`를 배포하도록 설정합니다.
- **Netlify / Vercel**: 빌드 명령 `npm run build`, 출력 폴더 `dist`로 지정합니다.

## 기술 구성

- React 19 + TypeScript + Vite, Tailwind CSS 4
- 모든 과학 그림은 SVG로 직접 그렸고, 애니메이션은 CSS와 `requestAnimationFrame`만 사용합니다(물리 엔진 없음).
- 서체: Freesentation(눈누 CDN), 불러오지 못하면 함께 번들된 Pretendard로 대체됩니다.

```
src/
├─ App.tsx                     # 목록/학습 화면 전환(해시 라우팅)
├─ data/
│  ├─ lessons.ts               # ★ 설명 문장·확인 문제 데이터(수정은 이 파일에서)
│  └─ types.ts
├─ components/
│  ├─ ChapterGrid.tsx          # 학습 카드 목록
│  ├─ LessonPage.tsx           # 팝업북 페이지(단계 진행, 모드, 다시 보기)
│  ├─ SceneViewer.tsx          # 인터랙티브 그림 영역 틀
│  ├─ StepControls.tsx         # 이전 / 다시 보기 / 다음
│  ├─ ConceptExplanation.tsx   # 단계별 설명
│  ├─ ConceptQuiz.tsx          # 확인 문제와 피드백
│  ├─ ProgressTracker.tsx      # 진행률, 단계 표시
│  ├─ svg.tsx                  # 화살표·라벨·말풍선 등 SVG 부품
│  └─ ui.tsx                   # 버튼·토글·범례·주석
├─ scenes/                     # 개념별 독립 SVG 장면 컴포넌트 10개 + 카드 썸네일
└─ lib/                        # 애니메이션 훅, 진도 저장
```

### 설명·문제 수정하기

`src/data/lessons.ts`에서 문장을 고치면 됩니다. `steps[i]`는 그림의 i번째 단계와 연결되며, 북반구/남반구처럼 그림 안에서 고르는 모드에 따라 문장을 달리하려면 `text`에 `{ N: '...', S: '...' }` 형태로 적습니다. 확인 문제의 `reviewStep`은 오답일 때 다시 보여 줄 단계(0부터)입니다.

## 과학적 정확성 점검 내역

| 항목 | 그림에서의 표현 |
|---|---|
| 수압 | 수압 = ρgh(대기압 제외), 10 m마다 약 1기압. 밀도 차에 따른 막대 차이는 과장했음을 주석으로 표시 |
| 수압경도력 | 같은 깊이에서 수압이 높은 쪽(해수면이 높은 쪽) → 낮은 쪽, 수평 방향 |
| 전향력 | 항상 운동 방향에 수직(직각 표시), 북반구 오른쪽·남반구 왼쪽, 크기는 속력에 비례 |
| 지형류 | 수압경도력(북쪽)과 전향력(남쪽)이 평형 → 북반구 동쪽, 남반구 서쪽으로 흐름. 실제로는 진동하며 평형에 접근한다는 주석 |
| 에크만 | 표층 해류 45°(이상화 모형 주석), 층마다 같은 비율로 회전·감쇠하는 나선, 에크만 수송은 90°로 별도 색 |
| 용승·침강 | 북반구, 서쪽 육지 해안: 남풍 → 수송이 먼바다 쪽 → 발산 → 용승 / 북풍 → 수렴 → 침강. 단면의 바람 기호(⊗, ⊙)와 지도 삽화로 방향 확인 |
| 해파 | 선형 심해파 이론의 입자 궤도(마루에서 진행 방향, 반지름 e^(−kz)로 감소, 파장의 1/2 깊이에서 약 4%) |
| 쇄파 | 파속·파장은 분산 관계 ω² = gk·tanh(kh)로 계산(주기 일정). 파고 증가는 과장했음을 주석으로 표시 |
| 지진해일 | 해저 융기 → 해수 전체 변위 → 양방향 전파, 속력 √(gh) (4000 m ≈ 700 km/h, 100 m ≈ 110 km/h, 10 m ≈ 36 km/h) |
| 조석 | 기조력 벡터 분포(천체 쪽·반대쪽으로 부풂), 달:태양 ≈ 1:0.46 합성. 삭·망 사리, 상현·하현 조금 |
| 조위 | 반일주조 주기 12시간 25분, 만조·간조·조차 표시, 조류(창조류·낙조류·정조)는 수평 화살표로 별도 표시 |
