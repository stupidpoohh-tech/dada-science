# 원문 파일 형식

대단원마다 Markdown 파일 하나(`ocean.md`, `atmosphere.md`)를 씁니다. 소챕터 목록과 제목은 `src/content/units.ts`에 있습니다.

| 쓰는 법 | 결과 |
|---|---|
| `@chapter ocean-01` | 이 줄 아래가 해당 소챕터의 본문 |
| `#### [수직] {#ocean-01-vertical}` | 소제목(`###`은 더 큰 제목) |
| 빈 줄로 구분한 문장 `… {#ID}` | 문단 |
| `- 항목 {#ID}` / `  - 하위 항목` | 글머리 목록(2칸 들여쓰면 하위) |
| `> [정의] 내용 {#ID}` | 강조 상자 |
| `$$ id=… caption="…"` 줄, 수식, `$$` 줄 | 수식 상자 |
| `@table id=… caption="…"` 다음 줄부터 `\| … \|` | 표 |
| `@figure id=… fig=키 popup=팝업ID@단계` 다음 줄에 캡션 | 그림(`fig`: `src/figures`, `thumb`: 팝업 썸네일, `src`: `public/` 이미지 경로) |
| `@row widths=3,2` … `@col` … `@end` | 좌우 배치(휴대폰에서는 위아래) |
| `@popups ids=ekman,upwelling` | 움직이는 그림 바로가기 줄 |
| `@todo` / `@demo` 다음 줄에 문장 | 입력 대기 / 데모 표시 |

인라인: `**굵게**`, `==핵심 용어==`, `!!빨간 글씨!!`, `::네모 표시::`, `<u>밑줄</u>`, `^{위첨자}`, `_{아래첨자}`, `[[보이는 글|popup:ekman@2]]`(팝업 열기), `[[보이는 글|#블록ID]]`(원문 안 이동).

**블록 ID(`{#…}`, `id=`)는 필기와 문제 연결의 기준입니다.** 문장을 고쳐도 ID는 그대로 두세요. ID를 빠뜨리면 임시 ID가 붙고 개발 도구 콘솔에 경고가 표시됩니다.
