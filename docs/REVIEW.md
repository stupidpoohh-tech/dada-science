# 원문 검토 목록

원문은 **손글씨 노트 사진**(`source/KakaoTalk_…_04~07.jpg`)을 기준으로 옮겼습니다.
정리 이미지(`.png`)와 Word 텍스트(`text.docx`)는 손글씨를 옮기는 과정에서 달라진 곳이 많아 배치 확인용으로만 사용했습니다.
아래 항목은 판독이 불확실하거나 내용 확인이 필요한 곳입니다. 확인 후 `src/content/manuscripts/*.md`에서 고치면 바로 반영됩니다.

## 1. 정리 이미지·Word 텍스트와 다르게 옮긴 곳(손글씨 기준)

| 위치 | 정리본/Word | 손글씨(반영) |
|---|---|---|
| Ⅱ-01 [수직] 그림 말풍선 | 한계 / (없음) | 무거워 |
| Ⅱ-01 [수직] | 주요 압력 | 작은 압력 |
| Ⅱ-01 [전향력] 그림 설명 | 반시계 방향 회전 → 오른쪽 편향 / 시계 방향 → 안쪽·극지방으로 조밀하게 작용 | (북) 물체 운동 방향의 '오른쪽' 직각 방향, (남) '왼쪽' 직각 방향으로 전향력 작용 |
| Ⅱ-02 에크만 나선 | 바람 저항 심도 | 마찰 저항 심도 |
| Ⅱ-02 대기 대순환 | 저위도/중위도, 계절 변화·공간 변화 | 북동 무역풍 위도 0~30° 서쪽 방향, 편서풍 30~60° 동쪽 방향 → 지형류 |
| Ⅱ-02 지형류 형성 | 거대한 경사, 동서 방향 | 해수면 경사, 등수압선에 나란하게 |
| Ⅱ-03 해파 | 이동X 단순 전달 | 이동 X, E만 전달 |
| Ⅱ-03 풍랑 | 마주가 보족 … 방향 탄력 | 마루가 뾰족 (바람 부는 해역 → 풍역대) 방향 일정 |
| Ⅱ-03 표 | 깊은 곳: 주파수, 주기 | 깊은 곳: 작아져 무시 |
| Ⅱ-03 만·곶 | 반/파곡/굴절(축파) | 만: 퇴적(모래사장), 곶: 침식(절벽), 해파는 곶으로 굴절 |
| Ⅱ-05 조석 주기 | 지역에 따른 달의 중력(6.5)까지 0.95 | 자전하는 동안 달도 공전(6.5°)해서 이동, 지구가 더 25분 자전해야 |
| Ⅲ-01 대기 조성 | 수증각탄소 | 이산화 탄소 |
| Ⅲ-03 습윤 단열 감률 예 | 손난로 압축 → 고체 / 전선은 아래→그래 | 손난로 액체 → 고체 따뜻! |
| Ⅲ-03 대기 안정도 | 중립안정 | 조건부 불안정: (불포화) 안정, (포화) 불안정 |
| Ⅲ-03 강수 | 냉랭형/냉결 | 빙정설, 빙정(얼음) |
| Ⅲ-06 대기 대순환 | 0°: 해들리, 30°: 페렐, 60°: 경계 | 0~30° 해들리, 30~60° 페렐, 60~90° 극순환 |
| 단원 번호 | 정리본 Ⅱ. 강수과정과 대기의 운동 | 손글씨 Ⅲ. 강수 과정과 대기의 운동 (지시서의 Ⅰ과도 다름) |

## 2. 손글씨 판독이 불확실한 곳

| 위치 | 현재 옮긴 내용 | 확인할 점 |
|---|---|---|
| Ⅱ-02 쿠로시오 메모(빨간 글씨) | 흑조 강하다 (쿠로시오 해류) / 시계 방향 순환 / 표류하면 미국 가! | 첫 글자 '高'와 '흑조', '표류'의 판독 |
| Ⅱ-03 소제목 | [파장과 수심의 비교] | '비교' 또는 '비율' |
| Ⅱ-05 조금·사리 괄호 | 조금(소조): 상현·하현 / 사리(대조): 삭·망 | 노트의 괄호가 가리키는 범위 |
| Ⅱ-05 기조력 옆 메모 | (생략) | "* ○○이야기"로 보이는 검은 글씨 판독 불가 |
| Ⅲ-02 지구 열수지 | 수지 타산! 돈 벌림 생각! / 온도로 올림! | 두 메모의 정확한 글자 |
| Ⅲ-03 단열 압축 예 | (자동차 엔진) | '디젤 엔진' 등 다른 글자일 가능성 |
| Ⅲ-03 이슬점 감률 | 2℃ | 2℃ 위아래에 5℃가 함께 적혀 있음(고친 흔적으로 보고 2℃로 옮김) |
| Ⅲ-06 제트류 | 한대 전선 제트류 > 아열대 제트류 | '>' 기호의 의미(세기 비교인지 나열인지) |
| Ⅲ-06 편서풍 파동 그림 | 기압 마루·기압골·수렴·발산 → 지상 고기압·저기압 | 그림의 화살표 배치를 교과서식 그림으로 다시 그림 |

## 3. 내용 확인이 필요한 곳(원문을 고치지 않고 표시만 함)

| 위치 | 원문 | 검토 의견 |
|---|---|---|
| Ⅲ-06 태양 상수 | 태양 상수 = 1367 W | 단위는 W/m² 입니다. |
| Ⅲ-03 이슬점 감률 이유 | 기온이 낮아지며 수증기압이 낮아지기 때문 | 상승한 공기가 팽창(기압 감소)하면서 수증기압이 낮아지기 때문으로 설명하는 경우가 많습니다. |
| Ⅱ-01 수평 ② | 더워서 밀도↓ 압력↓ / 추워서 밀도↑ 압력↑ | 같은 깊이에서 압력은 위에 놓인 해수 전체의 무게로 정해지므로, 해수면 높이와 함께 설명하면 정확합니다. |
| Ⅲ-05 경도풍 | (고) ⇒ 빠름! | 같은 기압 경도력일 때 고기압 쪽 경도풍이 더 빠르다는 뜻으로 보입니다. |

## 4. 아직 제공되지 않은 자료

- 기본 예제·내신 대비 문항: 현재 기능 확인용 **데모 문항**(Ⅱ 단원 12문항, `demo: true`)만 있습니다. Ⅲ 단원은 비어 있습니다.
- 노트의 그림은 같은 구성으로 SVG로 다시 그렸습니다. 원본 사진은 교재 화면의 ‘원본 손글씨 노트 보기’에서 볼 수 있습니다.
