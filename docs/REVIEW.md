# 원문 검토 목록

원문은 **손글씨 노트 사진**(`source/KakaoTalk_…_04~07.jpg`)을 기준으로 옮겼습니다.
정리 이미지(`.png`)와 Word 텍스트(`text.docx`)는 손글씨를 옮기는 과정에서 달라진 곳이 많아 배치 확인용으로만 사용했습니다.
아래 항목은 판독이 불확실하거나 내용 확인이 필요한 곳입니다. 확인 후 `src/content/manuscripts/*.md`에서 고치면 바로 반영됩니다.

## 4. 아직 제공되지 않은 자료

- 기본 예제·내신 대비 문항: 현재 기능 확인용 **데모 문항**(Ⅱ 단원 12문항, `demo: true`)만 있습니다. Ⅲ 단원은 비어 있습니다.
- 노트의 그림은 같은 구성으로 SVG로 다시 그렸습니다. 원본 사진은 교재 화면의 ‘원본 손글씨 노트 보기’에서 볼 수 있습니다.

### 정답 비공개의 한계

정답·해설은 문제와 다른 파일에 두고, 학생이 정답 확인·채점을 하기 전에는 화면에 그리지 않습니다. 다만 서버 없이 브라우저에서만 동작하는 웹이므로, 개발자 도구로 프로그램 파일을 직접 열어 보는 것까지 막을 수는 없습니다. 이를 막으려면 채점을 서버에서 하는 구조가 필요합니다.
