## 실제 iPad에서 확인이 필요한 항목

일반 브라우저 자동 테스트로는 아래를 완전히 검증할 수 없습니다.

1. **iPadOS Safari에서 Apple Pencil 필기 중 페이지가 움직이지 않는지**: 펜 터치(`touchType: 'stylus'`)의 기본 동작만 막도록 구현했습니다. 자동 테스트에서는 이 값을 만들 수 없습니다.
2. **필기 도구를 켠 상태에서 손가락 스크롤이 자연스러운지**(관성 스크롤 포함).
3. **필압 표현**: Apple Pencil의 `pressure` 값이 들어오면 선 굵기가 변하도록 했습니다. 필압이 없으면 속도 기반 굵기로 그립니다.
4. 팝업 안 ‘그림에 필기’에서 손가락·펜 모두 필기되고, 끄면 그림 조작이 다시 되는지.
5. 가로·세로 회전 직후 필기 위치(판형 배율이 바뀌는 순간).
6. ‘필기 백업 파일 내보내기’ 시 iPadOS의 파일 저장 동작.
7. 화면 확대(핀치 줌) 상태에서의 필기 좌표.
